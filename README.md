### 🕯️ Velvia — Tienda online artesanal

Proyecto Intermodular del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web.

Aplicación web completa desarrollada desde cero para gestionar el funcionamiento de una tienda online de productos artesanales.

#### 📸 Vista previa

- consulta de pedidos
- panel de administración
